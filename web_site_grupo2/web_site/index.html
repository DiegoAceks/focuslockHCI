PREGUNTAS FRECUENTES

Todo más claro.

Respuestas rápidas antes de comenzar.

¿FocusLock bloquea mis redes sociales de verdad?+

Esta versión es un prototipo interactivo. Permite configurar una lista de distracciones, pero no bloquea páginas ni aplicaciones fuera de esta web.

¿Se guardan mis sesiones?+

Sí. Los bloques de enfoque completados se almacenan en el navegador mediante localStorage. Puedes borrar el historial cuando quieras.

¿Puedo usarlo en mi celular?+

La interfaz se adapta a pantallas móviles. Para evitar pausas imprevistas en el temporizador, es mejor mantener esta pestaña activa.

¿La beta ya envía solicitudes reales?+

Por ahora el formulario valida los datos y muestra una confirmación de demostración. No envía información a un servidor.
